# 2. 产品主线：首页成长 / 历练 / 任务经营线（第一优先级）

## 2.1 为什么这是当前首要任务

本项目的差异化不在“只是能玩游戏”，而在于：

- 玩家进入后不能只看到游戏列表
- 必须立即感知到**成长、升级、经营、收获**
- 玩家需要被任务驱动，形成持续游玩动机
- 首页与历练页必须承担“留存驱动”作用

目标不是单纯展示游戏，而是形成：

**进入首页 → 接收任务 → 体验游戏 → 完成目标 → 获取奖励 → 等级成长 → 解锁更多内容 / 提升身份感 → 继续游玩**

这是当前版本上线前最核心的产品建设任务。

## 2.5 保底方案要求（必须做）

即使服务端未就绪、网络异常或远端配置为空，App 也要有“最小可运行内容”。

### 必备保底内容
- [ ] 保底首页任务数据
- [ ] 保底玩家成长数据
- [ ] 保底等级配置
- [ ] 保底奖励配置
- [ ] 保底游戏配置
- [ ] 保底 SDK 配置
- [ ] 保底空状态与引导文案

### 要求
- [ ] 即便后端异常，首页也不能是“空白”
- [ ] 即便远端任务拉取失败，也要让玩家看到一个最小成长闭环
- [ ] 即便没有新活动，也要有默认每日任务和新手任务
